# Geometry

All core cases except the Stanford Dragon generate geometry using StellaGmsh. The attritor
illustration also uses figures/attritor/attritor.geo. Generated boundary vertices and triangles
are exported alongside particles for independent checking.

Download the original Stanford Dragon STL from https://www.thingiverse.com/thing:2785144/files
and save it as meshes/dragon2.stl. Expected SHA-256:
`fa680acba2c958c917fa6b2fe561c0ef56c969b4c05ed19872b49b6c7ec4e118`.
Expected triangles: 100,000; signed enclosed volume: 9967.791784635354 mesh units cubed.
Do not rescale or repair this file for the historical comparison. Its redistribution licence
must be confirmed before bundling it in a public release. The local original is not copied here.
