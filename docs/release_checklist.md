# Release checklist

The reproducibility repository is public. Remaining release tasks:

- Check the Stella source pin and manifests against the version selected for the release.
- Check insertion and independent validation from a fresh clone after the source update,
  and update the recorded verification.
- Add the final manuscript citation, release/archive DOI and funding information as appropriate.

The repository code is licensed under AGPL-3.0. The Dragon mesh is download-only and has
its own licence. Original reference assemblies are not distributed; readers can regenerate
assemblies with the case scripts and independently validate the new outputs.
